## 🏡 معرفی

**VIVO** یک نرم‌افزار مدیریت کلبه و اقامتگاه است که برای مدیریت اطلاعات مسافران، کلبه‌ها، تاریخ اقامت، مدارک و پرداخت‌ها طراحی شده است.

این برنامه با رابط کاربری دسکتاپ ساخته شده و برای استفاده مدیریتی در مجموعه‌های اقامتی مناسب است.

---

## ✨ امکانات

### 👤 مدیریت مسافران

* ثبت مسافر جدید
* ویرایش اطلاعات مسافر
* حذف مسافر
* مشاهده اطلاعات کامل مسافر
* جست‌وجوی سریع
* جست‌وجو بر اساس نام و نام خانوادگی
* جست‌وجو بر اساس شماره تلفن
* فیلتر بر اساس شماره کلبه
* فیلتر بر اساس تاریخ ورود
* فیلتر بر اساس تاریخ خروج
* نمایش وضعیت کامل یا ناقص بودن مدارک
* باز کردن سریع پنجره ویرایش با دوبار کلیک روی ردیف مسافر

### 🏠 مدیریت کلبه‌ها

* پشتیبانی از ۱۶ کلبه
* انتخاب کلبه هنگام ثبت مسافر
* بررسی تداخل رزروها
* جلوگیری از رزرو هم‌زمان یک کلبه
* مشاهده وضعیت کلبه‌ها

### 📅 تقویم

* تقویم شمسی
* انتخاب تاریخ ورود
* انتخاب تاریخ خروج
* استفاده از تقویم در بخش جست‌وجو
* اعتبارسنجی تاریخ‌ها
* بررسی صحیح بودن ترتیب ورود و خروج

### 📎 مدیریت مدارک

* افزودن مدارک مسافر
* ذخیره مسیر مدارک
* مشاهده مدارک
* حذف مدارک
* نمایش وضعیت وجود مدارک در جدول
* باز کردن سریع پنجره مدارک با دوبار کلیک روی ستون مدارک

### 💳 مدیریت پرداخت‌ها

امکان ثبت اطلاعات پرداخت شامل:

* صندوق
* کارتخوان دفتر
* کارتخوان کافه
* کارتخوان فروشگاه
* انتقال کارت‌به‌کارت
* ثبت دریافت‌کننده انتقال کارت‌به‌کارت

### 🔎 جست‌وجوی پیشرفته

سیستم جست‌وجوی VIVO به‌صورت لحظه‌ای عمل می‌کند.

با تغییر فیلترها، نتایج جدول به‌صورت خودکار به‌روزرسانی می‌شوند.

### 💾 پشتیبان‌گیری

* ایجاد نسخه پشتیبان از اطلاعات
* انتخاب محل ذخیره Backup
* نگهداری اطلاعات پشتیبان
* امکان استفاده از Backup برای بازیابی/ادغام اطلاعات

### ⚙️ تنظیمات

* مدیریت مسیر ذخیره Backup
* ذخیره تنظیمات برنامه
* ایجاد خودکار فایل تنظیمات

### 🎨 رابط کاربری

* طراحی رابط کاربری دسکتاپ
* دکمه‌های گرافیکی بهبود‌یافته
* انیمیشن نرم هنگام فشرده شدن دکمه‌ها
* هماهنگی رنگ دکمه‌ها با تم برنامه
* دسترسی سریع‌تر به عملیات پرکاربرد

### 🔐 ورود

برنامه دارای صفحه ورود مدیریتی است و بخش‌های مدیریتی از طریق آن قابل دسترسی هستند.

| PyInstaller | ساخت فایل اجرایی EXE |
