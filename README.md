## 🏡 معرفی

**VIVO** یک نرم‌افزار مدیریت کلبه و اقامتگاه است که برای مدیریت اطلاعات مسافران، کلبه‌ها، تاریخ اقامت، مدارک و پرداخت‌ها طراحی شده است.

این برنامه با رابط کاربری دسکتاپ ساخته شده و برای مدیریت مجموعه‌های اقامتی با ۱۶ کلبه طراحی شده است.

---

## ✨ امکانات

### 👤 مدیریت مسافران

* ثبت مسافر جدید
* ویرایش اطلاعات مسافر
* حذف مسافر
* مشاهده اطلاعات کامل مسافر
* جست‌وجوی سریع و لحظه‌ای
* جست‌وجو بر اساس نام و نام خانوادگی
* جست‌وجو بر اساس شماره تلفن
* فیلتر بر اساس شماره کلبه
* فیلتر بر اساس تاریخ ورود
* فیلتر بر اساس تاریخ خروج
* نمایش وضعیت کامل یا ناقص بودن مدارک
* باز کردن سریع پنجره ویرایش با دوبار کلیک روی ردیف مسافر
* پشتیبانی از اطلاعات پرداخت مسافر

### 🏠 مدیریت کلبه‌ها

* پشتیبانی از ۱۶ کلبه
* انتخاب کلبه هنگام ثبت مسافر
* بررسی تداخل رزروها
* جلوگیری از رزرو هم‌زمان یک کلبه
* مشاهده وضعیت فعلی کلبه‌ها
* نمایش نام مسافر و تاریخ خروج کلبه‌های در حال استفاده

### 📅 تقویم رزرو کلبه‌ها

* تقویم شمسی مستقل برای مدیریت رزروها
* نمایش صحیح روزها و ماه‌های تقویم شمسی
* جابه‌جایی بین ماه‌ها با دکمه‌های جهت‌دار
* انیمیشن هنگام تغییر ماه
* نمایش دکمه‌های جداگانه برای کلبه‌های ۱ تا ۱۶
* انتخاب هر کلبه برای مشاهده رزروهای آن
* نمایش رزروها در ماه انتخاب‌شده و ماه‌های بعد
* نمایش بازه کامل اقامت با رنگ اختصاصی هر رزرو
* نمایش نیمه اول یا نیمه دوم کارت روز برای تاریخ ورود و خروج
* نمایش هم‌زمان دو رزرو متفاوت در یک روز، با دو رنگ و دو نام متفاوت
* نمایش نام و نام خانوادگی مسافر روی بازه رزرو
* حفظ خوانایی شماره روزها روی کارت‌های رزرو
* نمایش روزهای آزاد با ظاهر پیش‌فرض تقویم

### 📎 مدیریت مدارک

* افزودن مدارک مسافر
* ذخیره خود فایل مدارک داخل پایگاه داده برنامه
* نگهداری مدارک به‌صورت BLOB در SQLite
* عدم وابستگی مدارک ثبت‌شده به مسیر اصلی فایل در کامپیوتر
* امکان جابه‌جایی یا حذف فایل اصلی بدون از دست رفتن مدرک ذخیره‌شده در VIVO
* مشاهده مدارک مسافر
* حذف مدارک
* نمایش وضعیت وجود مدارک در جدول
* باز کردن سریع پنجره مدارک با دوبار کلیک روی ستون مدارک
* پشتیبانی از انتقال مدارک هنگام بازیابی Backup

### 💳 مدیریت پرداخت‌ها

امکان ثبت اطلاعات پرداخت شامل:

* صندوق
* کارتخوان دفتر
* کارتخوان کافه
* کارتخوان فروشگاه
* پرداخت نقدی
* انتقال کارت‌به‌کارت
* ثبت دریافت‌کننده انتقال کارت‌به‌کارت

### 🔎 جست‌وجوی پیشرفته

سیستم جست‌وجوی VIVO به‌صورت لحظه‌ای عمل می‌کند.

با تغییر فیلترها، نتایج جدول به‌صورت خودکار به‌روزرسانی می‌شوند.

امکان جست‌وجو و فیلتر بر اساس:

* نام و نام خانوادگی
* شماره تلفن
* شماره کلبه
* تاریخ ورود
* تاریخ خروج
* وضعیت مسافر

### 💾 پشتیبان‌گیری

* ایجاد نسخه پشتیبان از پایگاه داده
* انتخاب محل ذخیره Backup
* نگهداری اطلاعات پشتیبان
* امکان افزودن و ادغام Backup با اطلاعات فعلی برنامه
* حفظ اطلاعات فعلی هنگام افزودن Backup
* انتقال اطلاعات مسافران از Backup
* انتقال مدارک ذخیره‌شده داخل SQLite همراه Backup
* جلوگیری از ایجاد مدارک تکراری هنگام ادغام Backup
* پشتیبانی از مدارک قدیمی که به‌صورت مسیر فایل ذخیره شده‌اند

### ⚙️ تنظیمات

* مدیریت مسیر ذخیره Backup
* نمایش آخرین Backup
* نمایش تاریخ و ساعت آخرین Backup
* نمایش حجم Backup
* ذخیره تنظیمات برنامه
* ایجاد خودکار فایل تنظیمات
* نمایش تعداد مسافران
* نمایش حجم پایگاه داده

### 🎨 رابط کاربری

* طراحی رابط کاربری دسکتاپ
* تم هماهنگ در بخش‌های مختلف برنامه
* دکمه‌های گرافیکی بهبود‌یافته
* آیکون‌های اختصاصی برای عملیات مختلف
* انیمیشن نرم هنگام فشرده شدن دکمه‌ها
* هماهنگی رنگ دکمه‌ها با تم برنامه
* دسترسی سریع‌تر به عملیات پرکاربرد
* رابط کاربری اختصاصی برای تقویم رزرو

### 🔐 ورود

برنامه دارای صفحه ورود مدیریتی است و بخش‌های مدیریتی از طریق آن قابل دسترسی هستند.

## 🛠 تکنولوژی‌ها

| تکنولوژی      | کاربرد                    |
| ------------- | ------------------------- |
| Python        | زبان اصلی برنامه          |
| PySide6       | رابط کاربری دسکتاپ        |
| SQLite        | پایگاه داده               |
| BLOB / SQLite | ذخیره داخلی مدارک مسافران |
| PyInstaller   | ساخت فایل اجرایی EXE      |
| Inno Setup    | ساخت Installer            |
| JSON          | ذخیره تنظیمات             |
